# Changelog

## 0.1.0 (2026-11-12)

First version.

- Theory engine (`js/theory.js`) with correct note spelling, 12 scales/modes, 33 chord types, Roman numeral
  parsing and analysis, harmonic function, next-chord suggestions, cadence detection, key and chord finder.
- Tabs: Scales & Degrees, Chords in Key, Chord Builder, Progressions, Intervals, Find Key & Chord.
- Interactive fretboard with colour-coded chord tones, note/degree labels, 5 tunings and click-to-play.
- Built-in synth for notes, strums, arpeggios and progression playback (tempo, beats per chord, loop).
- 14 automated tests (`npm test`) and GitHub Actions CI.
- Docs: README, roadmap, how-it-works notes, beginner Git guide.
